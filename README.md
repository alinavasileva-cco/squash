# Squash Hub — личный календарь тренера

Мобильное устанавливаемое веб-приложение для Android и iPhone (PWA). Минималистичный календарь без посторонних событий: **записать тренировку или добавить ученика**.

## Возможности второй версии

- Календарь **месяц / неделя / свой период** с выбором начала и конца диапазона; выбор даты и времени тренировки.
- Первичная — **1 200 ₽**, индивидуальная для одного или двух учеников — **1 900 ₽ за всю тренировку**, групповая — количество участников × **подтверждённый** тариф за человека (пока ставка не задана).
- Выбор учеников при записи; создание нового ученика прямо из формы.
- Три состояния записи: запланирована, проведена, отменена. Отмена сохраняет историю и исключает её из начислений; удаление полностью убирает запись после подтверждения.
- Карточки учеников с изменением уровня и заметок. Уровни сквоша: Pre-Beginner, Beginner, B (практическая клубная шкала, не единый мировой стандарт).
- Отдельная вкладка **«Статистика и доход»**: неделя, месяц, произвольные даты; запланированные, проведённые, отменённые и повторные тренировки, плановые суммы и заработок. Повторным считается занятие с учеником, который был в более ранней неотменённой записи.
- Исправлена прокрутка формы на Android: список учеников прокручивается отдельно, кнопки сохранения закреплены в нижней части окна.
- Работает без интернета после первого открытия и установки благодаря service worker.
- Резервная копия JSON и восстановление из файла.

## Как опубликовать бесплатно

1. GitHub → **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. В поле **Branch** выберите `main`, каталог **`/ (root)`**, нажмите **Save**.
4. Дождитесь появления GitHub Pages URL; ссылка будет выглядеть как `https://<your-login>.github.io/squash/`.

Это **не** ссылка на рабочее приложение, пока GitHub Pages не включён и публикация не завершилась.

## Установка на телефон

- **iPhone:** откройте опубликованное приложение в Safari → «Поделиться» → «На экран „Домой“» → «Добавить».
- **Android:** откройте опубликованное приложение в Chrome → `⋮` → «Установить приложение» / «Добавить на главный экран».

Иконка работает на обеих платформах. Отдельные APK/IPA в этом репозитории **пока не созданы**.

## Важное ограничение хранения

**Версия 1 сохраняет записи только в `localStorage` текущего браузера и устройства**. Она не синхронизируется между Android и iPhone, не доступна из ChatGPT и Notion и не хранит личные данные учеников в публичном репозитории. Для защиты записей регулярно делайте резервную копию через меню `⋯`.

Для синхронизации между устройствами, входа по аккаунту и изменения записей голосом через ChatGPT потребуется отдельное облачное хранилище с авторизацией и серверным API. Эти возможности запланированы для следующего этапа, но не представлены как уже работающие.

## Технологии

Vanilla JavaScript, HTML, CSS, Web App Manifest и service worker. Без внешних библиотек и обязательной подписки. Изменения кода можно вносить напрямую в GitHub.

## Источники клубной градации

- US Squash: https://ussquash.org/rating-criteria/ (буквенные грейды D/C/B/A/AA).
- Club Towers: https://clubtowers.com/junior-squash-northants-grand-prix-8th-february-2026/ (A–E grades, уровни зависят от турнира).

Уровни Pre-Beginner и Beginner добавлены как удобные вводные ступени для тренера; не считаются официально унифицированной системой федерации.
